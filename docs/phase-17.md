# Phase 17: README first-run guide

The README now explains how to run the existing single-owner testnet demo.
It covers dependency installation, root and browser environment files, and the
three separate test-ETH balances: owner wallet, relayer, and account contract.

It gives deployment commands for the three public testnets and explains that a
new deployment replaces only the local record for that chain. It then gives the
two-terminal startup commands and the exact website action order.
The guide also explains page reload behaviour and local Anvil mode.

No application or contract code changed, so no automated tests were required.
README links and Markdown structure were reviewed manually.
